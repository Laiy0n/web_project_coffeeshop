# Grão Dourado

Página web de uma cafetaria, feita como projeto de HTML e CSS avançado
na TripleTen.

## Descrição

Grãos selecionados, aromas envolventes e sabores preciosos: descubra o lado
dourado de cada momento no Grão Dourado.

A página tem quatro secções:

- **Cabeçalho** com o menu de navegação, o título, a imagem do café e o
  horário e morada.
- **Receitas** com dois vídeos incorporados do YouTube (Aeropress e Prensa
  Francesa).
- **Reserva de mesa**: formulário com nome, número de convidados, data e hora
  e e-mail, com validação nativa do browser.
- **Rodapé** com o logótipo, as redes sociais e o copyright.

### Tecnologias utilizadas

- HTML5 semântico (`header`, `nav`, `main`, `section`, `footer`)
- CSS3: Flexbox, posicionamento absoluto e relativo, `z-index`, transições
  e estados `:hover` e `:focus`
- Metodologia BEM e estrutura de ficheiros BEM Flat
- normalize.css
- Google Fonts (Inter e Noto Serif)
- Git e GitHub

## Planos de melhoria

- Tornar a página responsiva para outros dispositivos.
- Fazer com que o formulário de reserva envie os dados de verdade.
- Criar uma secção com menus de bebidas e comida.

## Como ver o projeto

Abre o ficheiro `index.html` no browser.
